<h2>About The Project:</h2>
<p>This is a Ride Sharing Service website designed for individuals who frequently travel and want to share rides with others. The project is aimed at helping users connect and share rides to reduce costs and environmental impact. The website allows users to register by entering their phone number or email and access various benefits.</p>
</div>

<div id="description">
<h2>Description:</h2>
<p>The main goal of this project was to create a user-friendly platform for ride-sharing. The website includes several sections like registration (via phone or email), a "How It Works" section, and a "Benefits" section to help users understand the advantages of using the service. It was inspired by a Figma template, which provided the basic design structure for the project. The website is responsive and visually attractive, ensuring compatibility across devices.</p>
</div>
